# Gemini Clone

A simple Gemini AI clone built with **React, Vite, and the Google Gemini API**.

## Features

- Chat with Gemini (Flash 3.5)
- AI-generated responses
- Recent prompts
- New Chat functionality
- Responsive UI
- Gemini-inspired interface

## Tech Stack

- React
- Vite
- JavaScript
- CSS
- Google Gemini API
